사건관리 도구 사용 안내


1. 무엇을 하는 도구입니까

   가. 새사건.js   사건 하나를 입력하면 표준 사건폴더, 사건표지, 유형별 진행점검표를
                   만들고 사건대장.csv에 한 줄을 등록합니다.
   나. 점검.js     이미 만든 사건폴더를 훑어 표준 폴더의 누락, 사건표지와 점검표의
                   누락, 비어 있는 폴더, 미처리 점검항목을 보고합니다. --보정을 붙이면
                   누락된 폴더를 만들고 사건대장을 다시 만듭니다.
   다. 사건유형.js 사건유형마다의 추가 폴더, 표준 서류, 진행점검표를 정의한 파일입니다.
                   실무가 바뀌면 이 파일만 고칩니다.
   라. 중복찾기.js  원드라이브나 내 PC의 폴더에서 내용이 완전히 같은 파일을 찾아
                   보고서를 만듭니다. 이름이 같다는 이유만으로는 중복으로 보지
                   아니하고, 파일의 내용을 SHA-256으로 해시하여 판정합니다.
   마. 사건폴더체계.txt  사무소의 표준 체계를 적은 문서입니다.

   Node 외의 설치가 필요하지 아니합니다.


2. 새 사건을 만드는 방법

   node 사건관리/새사건.js --채권자 "OO농업협동조합" --채무자 "김OO" --유형 임의경매 --법원 울산지방법원 --청구금액 "250,000,000원"

   가. 사건유형의 목록을 보려면    node 사건관리/새사건.js --목록
   나. 만들어질 내용만 미리 보려면 위 명령의 끝에 --확인 을 붙입니다
   다. 사건번호는 접수연도 기준으로 자동으로 채번합니다. 직접 지정하려면 --사건번호 2026-007
   라. 담당자를 바꾸려면 --담당 홍길동


3. 사건폴더를 점검하는 방법

   node 사건관리/점검.js              점검 결과만 보고합니다
   node 사건관리/점검.js --보정       누락된 표준 폴더를 만들고 사건대장을 다시 만듭니다


4. 보관 위치

   기본값은 이 저장소의 바깥인 ..\사건폴더 입니다. 다른 곳에 두려면 두 가지 방법이 있습니다.
   가. 실행할 때마다 지정      --루트 "D:\사무소\사건폴더"
   나. 환경변수로 고정         CASE_ROOT=D:\사무소\사건폴더

   사건폴더는 의뢰인의 비밀이므로 저장소에 올리지 아니합니다. .gitignore가 /사건폴더/를
   제외하도록 되어 있습니다.


5. npm 명령으로 쓰는 방법

   npm run 새사건 -- --채권자 "OO농협" --채무자 "김OO" --유형 임의경매
   npm run 사건점검 -- --보정


6. 유형이나 점검표를 고치려면

   사건관리/사건유형.js를 열어 해당 유형의 추가폴더, 서류, 점검표를 고칩니다. 고친 다음
   node 사건관리/점검.js --보정 을 실행하면 이미 만들어 둔 사건폴더에도 새 표준 폴더가
   만들어집니다. 다만 이미 만든 00_진행점검표.txt는 덮어쓰지 아니하므로, 진행 중인
   사건의 점검표를 새로 받으려면 기존 점검표를 옮겨 두고 사건을 다시 만들거나 손으로
   항목을 더합니다.


7. 중복 파일을 정리하려면

   node 사건관리/중복찾기.js "C:\Users\사용자\OneDrive"
   node 사건관리/중복찾기.js "C:\Users\사용자\OneDrive" --격리 "D:\중복격리"

   가. 기본은 보고서만 만들고 아무것도 지우거나 옮기지 아니합니다.
   나. --격리를 붙이면 중복본을 지우지 아니하고 지정한 폴더로 원래의 폴더 구조를
       유지한 채 옮기기만 합니다. 내용을 확인하신 다음 직접 지우십시오.
   다. 사건폴더에는 주민등록등본.pdf 처럼 의뢰인마다 이름이 같고 내용이 다른 문서가
       많습니다. 이름만 보고 지우면 다른 의뢰인의 서류가 사라지므로, 이 도구는 반드시
       내용을 대조하여 완전히 같은 파일만 중복으로 판정합니다.
